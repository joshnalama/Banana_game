Event Driven Architectures
What in your code triggers events (e.g., GUI, buttons, timeout …)?
Implemented with a decoupled Pub/Sub EventBus (CustomEventBus) and Server-Sent Events:
  • GUI/Buttons: Numpad clicks emit puzzle:guess; SpongeBob clicks trigger giggle animations; mode cards trigger match transitions.
  • Keyboard: Physical keys 0–9 trigger digit answers; Spacebar skips countdown intros.
  • Timers: 15-second per-puzzle countdowns in Speed Rush trigger timeout losses; match countdown timers end duels.
  • Game State: Correct guesses fire puzzle:solved (synthesizing audio chimes and floating score badges); wrong guesses fire shake and buzzer events.
  • Network SSE: Server streams live opponent score and forfeit events to connected duelists.
Interoperability

Demonstrations & Protocols:
  • RESTful HTTPS/JSON: Node.js backend consumes the external puzzle API with a 3.5s timeout circuit breaker in server/src/routes.js.
  • Self-Healing Fallback: If the external API fails or lags, a local generator outputs mathematical SVG puzzles inline (data:image/svg+xml) without crashing.
  • Server-Sent Events (SSE): text/event-stream protocol synchronizes real-time 1v1 duels between server and browser.
  • Google OAuth 2.0 / OpenID Connect: Validates external Google ID tokens via google-auth-library.
Virtual Identity
How did you implement virtual identity in your code? (e.g., Passwords, Cookies, IP Numbers …)
  • Stateless JWT in HttpOnly Cookies: Signed tokens stored in secure, HttpOnly, SameSite cookies to block XSS theft.
  • Password Hashing: Passwords hashed with bcryptjs (10 salt rounds) before SQLite storage.
  • Instant Guest Identity: POST /api/auth/guest uses node:crypto to generate random nicknames and guest emails for instant play.
  • Google Sign-In: OpenID Connect token verification linked to local database accounts.
  • RBAC & Rate Limiting: Role-based access control (Player vs. Admin) and IP-based rate limiting (60 requests/15 min).
Any other interesting features:
  • Web Audio API Synthesizer: Zero external audio files; generates real-time polyphonic waveforms (bubble pops, chimes, buzzers).
  • HMAC-SHA256 Cryptographic Sealing: Puzzle answers are signed on the server and verified with timing-safe checks so clients cannot cheat.
  • Cursor Gaze-Tracking: SpongeBob's eyes compute trigonometric angles (atan2) to follow the user's cursor live.
  • Zero-Config SQLite: Built-in node:sqlite with Write-Ahead Logging (WAL) and automatic migrations.
